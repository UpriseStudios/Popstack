# Popstack

A colourful 3D block-removal puzzle game by Uprise Studios.

## Development branches

- `main`: browser game and web release.
- `android`: Android adaptation and mobile release preparation.

## Status

Phase 6.3 release candidate (`v0.6.3-rc1`) is prepared for import. **The game source has not yet been committed to this repository.**

## Development

The complete browser source and build files will be imported to `main` before platform development begins. Android development will track the same puzzle design and gameplay rules.
